# Security Policy

## Supported versions

Security updates are provided for the latest released minor version. The
project is currently in pre-release development and does not yet provide a
stable support guarantee.

## Reporting a vulnerability

Do not open a public issue containing a vulnerability, provider credential,
playlist, API response, or stream URL. Use GitHub's private security advisory
feature for this repository.

Remove credentials and personal provider data from every reproduction. If a
credential was exposed, revoke or rotate it immediately.
