# Xtream PHP Client

Xtream PHP Client é um cliente PHP 7.0+, independente de frameworks, para APIs
IPTV Player compatíveis com Xtream.

!!! warning "Estado de desenvolvimento"
    O projeto está em desenvolvimento pré-release. APIs públicas poderão mudar
    antes da versão 1.0.0.

O cliente planejado cobre informações da conta e do servidor, TV ao vivo, VOD,
séries, episódios, dados de EPG, geração de URLs de stream, paginação e
normalização das respostas.

## Princípios de projeto

- Compatibilidade com PHP 7.0 e versões atuais do PHP.
- Padrões seguros e tratamento explícito de erros.
- Sem dependência de frameworks.
- Credenciais do provedor nunca aparecem em logs ou exceções.
- Dados normalizados previsíveis sem perder acesso às respostas originais.
